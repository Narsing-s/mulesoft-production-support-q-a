# 06 — HTTP, REST & APIkit

## Slide 1 — HTTP Troubleshooting
Check URL/path, DNS/network, TLS, timeout, authentication, authorization, proxy/firewall and upstream health.

## Slide 2 — 401 vs 403
401 = authentication problem.
403 = authenticated caller is not authorized.

## Slide 3 — 404 After Deployment
Verify application startup, listener path, base path, APIkit/router, environment properties and gateway/ingress path.
