# 15 — Rapid Fire

## Slide 1
Choice = first matching route.
Scatter-Gather = parallel routes + aggregated result.
For Each = sequential.
Parallel For Each = concurrent.

## Slide 2
401 = authentication.
403 = authorization.
404 = resource/path.
429 = throttling.
5xx = server/upstream/runtime class.

## Slide 3
Continue = handled outcome.
Propagate = failure continues upward.
Correlation ID = transaction trace.
Idempotency = safe repeat.
RCA = cause + impact + recovery + prevention.

## Slide 4
Never hardcode secrets.
Never restart blindly.
Never reprocess blindly.
Always verify recovery.
Always document evidence.
